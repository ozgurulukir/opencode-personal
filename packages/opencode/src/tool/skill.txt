Load one or more specialized skills when the task at hand matches one of the skills listed in the system prompt.

Use this tool to inject the skills' instructions and resources into current conversation. The output may contain detailed workflow guidance as well as references to scripts, files, etc in the same directory as the skill.

You can load a single skill using the 'name' parameter, or multiple skills at once using the 'names' parameter (array of skill names, up to 10 per call).

The skill name(s) must match one of the skills listed in your system prompt.
