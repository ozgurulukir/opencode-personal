opencode, [Agent Client Protocol](https://agentclientprotocol.com) veya (ACP) dosyalarını destekleyerek onu doğrudan uyumlu editörlerde ve IDE'lerde kullanmanızı sağlar.

:::tip
ACP'yi destekleyen editörlerin ve araçların listesi için [ACP progress report](https://zed.dev/blog/acp-progress-report#available-now)'e bakın.
:::

ACP, kod editörleri ile AI kodlama ajanları arasındaki iletişimi standartlaştıran açık bir protokoldür.

---

## Yapılandırma

opencode'u ACP aracılığıyla kullanmak için düzenleyicinizi `opencode-personal acp` komutunu çalıştıracak şekilde yapılandırın.

Komut, opencode'u, editörünüzle stdio aracılığıyla JSON-RPC üzerinden iletişim kuran ACP uyumlu bir alt süreç olarak başlatır.

Aşağıda ACP'yi destekleyen popüler düzenleyicilere ilişkin örnekler verilmiştir.

---

### Zed

[Zed](https://zed.dev) yapılandırmanıza (`~/.config/zed/settings.json`) ekleyin:

```json title="~/.config/zed/settings.json"
{
  "agent_servers": {
    "OpenCode": {
      "command": "opencode-personal",
      "args": ["acp"]
    }
  }
}
```

Açmak için **Komut Paleti**'ndeki `agent: new thread` eylemini kullanın.

`keymap.json` dosyanızı düzenleyerek de bir klavye kısayolunu bağlayabilirsiniz:

```json title="keymap.json"
[
  {
    "bindings": {
      "cmd-alt-o": [
        "agent::NewExternalAgentThread",
        {
          "agent": {
            "custom": {
              "name": "OpenCode",
              "command": {
                "command": "opencode-personal",
                "args": ["acp"]
              }
            }
          }
        }
      ]
    }
  }
]
```

---

### JetBrains IDEs

[documentation](https://www.jetbrains.com/help/ai-assistant/acp.html) uyarınca [JetBrains IDE](https://www.jetbrains.com/) acp.json dosyanıza ekleyin:

```json title="acp.json"
{
  "agent_servers": {
    "OpenCode": {
      "command": "/absolute/path/bin/opencode-personal",
      "args": ["acp"]
    }
  }
}
```

Açmak için AI Chat agent seçicisindeki yeni 'OpenCode' ajanını kullanın.

---

### Avante.nvim

[Avante.nvim](https://github.com/yetone/avante.nvim) yapılandırmanıza ekleyin:

```lua
{
  acp_providers = {
    ["opencode"] = {
      command = "opencode-personal",
      args = { "acp" }
    }
  }
}
```

Ortam değişkenlerini iletmeniz gerekiyor:

```lua {6-8}
{
  acp_providers = {
    ["opencode"] = {
      command = "opencode-personal",
      args = { "acp" },
      env = {
        ANTHROPIC_API_KEY = os.getenv("ANTHROPIC_API_KEY")
      }
    }
  }
}
```

### CodeCompanion.nvim

opencode'u [CodeCompanion.nvim](https://github.com/olimorris/codecompanion.nvim)'de ACP ajanı olarak kullanmak için Neovim yapılandırmanıza aşağıdakileri ekleyin:

```lua
require("codecompanion").setup({
  interactions = {
    chat = {
      adapter = {
        name = "opencode",
        model = "claude-sonnet-4-5",
      },
    },
  },
})
```

Bu yapılandırma, CodeCompanion'ı opencode'u sohbet için ACP ajanı olarak kullanacak şekilde ayarlar.

Ortam değişkenlerini (`ANTHROPIC_API_KEY` gibi) iletmeniz gerekiyorsa, tüm ayrıntılar için CodeCompanion.nvim belgelerindeki [Configuring Adapters: Environment Variables](https://codecompanion.olimorris.dev/getting-started#setting-an-api-key)'ye bakın.

## Oturum seçenekleri

ACP istemcileri kullanılabilir modelleri, oturum modlarını, efor düzeylerini ve
komutları alabilir. İstemci bu kontrolleri sunuyorsa geçerli oturumun modelini,
modunu veya efor düzeyini değiştirebilirsiniz. İstemci ilgili ACP
güncellemelerini desteklediğinde opencode yanıtı ve araç ilerlemesini aktarır,
izin isteklerini iletir ve token kullanımını bildirir.

## Terminal desteği

ACP istemcisi terminal desteği bildirdiğinde opencode kabuk aracı çağrılarını
istemcinin oluşturduğu terminalde çalıştırır. Aksi durumda yerel kabuk kullanılır.
`OPENCODE_ACP_TERMINAL_BACKEND` değişkeniyle davranışı ayarlayın: `auto`
(varsayılan), `client` (istemci terminalini zorunlu kılar) veya `local` (her
zaman yerel kabuk kullanır):

```bash
OPENCODE_ACP_TERMINAL_BACKEND=client opencode-personal acp
```

İstemci terminali başlatılamazsa aynı komutu yerel kabukta ikinci kez çalıştırmak
yerine hata bildirilir.

## Question aracı

Her ACP istemcisi etkileşimli soru istemlerini desteklemediği için `question`
aracı varsayılan olarak devre dışıdır. Yalnızca uyumlu bir istemciyle etkinleştirin:

```bash
OPENCODE_ENABLE_QUESTION_TOOL=1 opencode-personal acp
```

## Destek

ACP, opencode oturumlarını protokol üzerinden sunar; istemci desteği değişebilir.
Yerleşik ve özel araçlar, MCP sunucuları, proje talimatları, biçimlendiriciler,
agent'lar ve izinler istemcinin yeteneklerine bağlı olarak kullanılabilir.
ACP `authenticate` isteği uygulanmamıştır; önce `opencode-personal auth login` ile giriş
yapın. `/undo` ve `/redo` gibi slash komutları ACP üzerinden kullanılamaz.
