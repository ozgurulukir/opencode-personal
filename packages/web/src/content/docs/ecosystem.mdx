This page summarizes the integration points implemented in this repository.

## Use providers and MCP servers

- Configure model providers in [Providers](../providers/).
- Connect external tools and resources with [MCP servers](../mcp-servers/).

## Extend agent behavior

- Add reusable instructions with [Agent Skills](../skills/).
- Create project-specific commands with [Commands](../commands/).
- Add local tools with [Custom Tools](../custom-tools/).
- Hook into runtime events with [Plugins](../plugins/).

## Build integrations

- Use the [JavaScript SDK](../sdk/) to call the server API.
- Connect compatible editors through [ACP](../acp/).
- Run repository automation with the [GitHub Action](../github/).
