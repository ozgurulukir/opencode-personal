This page summarizes the integration points implemented in this repository.

## Use providers and MCP servers

- Configure model providers in [Providers](/docs/providers).
- Connect external tools and resources with [MCP servers](/docs/mcp-servers).

## Extend agent behavior

- Add reusable instructions with [Agent Skills](/docs/skills).
- Create project-specific commands with [Commands](/docs/commands).
- Add local tools with [Custom Tools](/docs/custom-tools).
- Hook into runtime events with [Plugins](/docs/plugins).

## Build integrations

- Use the [JavaScript SDK](/docs/sdk) to call the server API.
- Connect compatible editors through [ACP](/docs/acp).
- Run repository automation with the [GitHub Action](/docs/github).
