## 2025-02-14 - Fusing multiple metrics calculations in high-frequency background tasks
**Learning:** In components monitoring performance like `DebugBar`, background tasks often calculate multiple different metrics on the same dataset. Relying on declarative chaining with `.reduce()` and `.filter()` forces redundant O(N) traversals per metric and allocates intermediate arrays, creating GC pressure that pollutes the very metrics being monitored.
**Action:** Always fuse redundant calculations over the same array into a single manual `for` loop within high-frequency loops (e.g. `requestAnimationFrame` callbacks) to ensure O(N) time complexity and zero allocations.
